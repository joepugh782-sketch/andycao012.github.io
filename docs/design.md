# 曹佳豪作品集网站首版

目标：帮助招聘方与潜在合作方快速认识电商设计师曹佳豪、浏览真实项目并发起联系。React + Vite，本地运行和预览，后续根据参考图迭代。

视觉：炭黑、暖白、少量橙红，以原作品集的光影封面为视觉线索。超大无衬线英文搭配中文标题、不对称作品网格、细线和宽留白。最大版心1700px，优先1440—1920px桌面，兼容移动端。

模块：全屏Hero（静音循环本地视频、标题、导航、联系、暂停）；个人介绍（真实头像、四项来源数据、三段来源经历、电话邮箱）；精选作品（每日黑巧、高露洁、一叶子、红色小象，可筛选与打开详情）；四项能力；全屏联系收尾。

交互：首屏错峰入场、滚动渐显、作品悬停、项目详情原生dialog（焦点管理、Escape关闭）、邮件与电话链接、复制联系方式、系统减少动态效果适配。详情内展示PDF提取的原始作品页。

真实性：所有作品和头像从用户给定PDF提取，不沿用工作区其他项目的概念素材。日期和项目数字遵照PDF，不推算业绩。视频由PDF封面裁切素材制作轻量循环运镜，非原生拍摄视频。

文件：src/content.js维护内容；App.jsx组织模块；components/管理项目浏览与联系；styles.css维护视觉；public/存放本地素材。无需后端、表单或远程服务。

验收：生产构建成功；桌面和手机无横向溢出；图片与视频可加载；导航、筛选、详情和关闭、复制与联系入口可用；无浏览器运行错误。
