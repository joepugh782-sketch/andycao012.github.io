# 首屏参考风格改版

设计解读：为招聘方和潜在合作方浏览的电商设计师作品集，借鉴参考图的超大橙色标题、文字层级和编辑式排版；根据用户反馈，背景保持原样。原站配色、真实信息与全站结构延续。

保留：React+Vite、暗色底、#ef4816、全站黑体、1700px版心、导航文案和锚点、第二屏磨砂悬浮导航、真实项目与头像原图、循环视频、减少动态效果、白色加粗按钮文字。

改版范围：仅首屏。将旧的两行标题改为大幅 DESIGN 字面；GOOD DESIGN / REAL IMPACT 保留为画面宣言；左侧保留介绍、6+经验和作品入口；恢复原有全屏动态视频、遮罩以及人物位移，不添加大头像或装饰边框。下方个人介绍头像保持原色静态，没有修改图像文件。

工程：Hero.jsx 与 hero.css 独立承载首屏，其他模块不变。已保存改版前 App.jsx 与 styles.css 至 tmp/hero-reference-backup，以及基准截图 preview/hero-before-editorial.png。

验收：1440、1920、1049、390、320px无溢出，桌面首屏CTA可见，人物不遮挡正文；视频播放/暂停和系统减少动态效果；浮动导航、手机菜单及作品筛选/详情继续可用。
