## 动效调整

`src/motion.js` 中的 `EASE`、各时间线 `duration` 和位置参数控制节奏；卡片交错间隔为 0.17–0.2 秒。动画只在首次进入时播放，筛选作品后重新建立当前列表的触发器。React 清理和屏幕尺寸/减少动态效果变化时会撤销相应时间线。

图片揭示层、视差层和原图悬停分别控制，避免同时修改同一个 transform。头像仅做遮罩揭示，保持原色和原比例。玻璃卡片只动画位移、透明度与小幅缩放，不动画模糊、阴影或玻璃参数，不长期设置 `will-change`。首屏原视频及下方 Grainient 背景保持原设计。
