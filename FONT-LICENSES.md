# Website font attribution

Chinese text uses **Source Han Sans CN VF**, from Adobe's official Source Han Sans project.

- Upstream: https://github.com/adobe-fonts/source-han-sans
- Original file: https://raw.githubusercontent.com/adobe-fonts/source-han-sans/release/Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2
- License: SIL Open Font License, Version 1.1.
- Copyright: Copyright 2014–2025 Adobe, with Reserved Font Name “Source”. The complete original notice and license are bundled in [LICENSE.txt](public/fonts/source-han-sans-cn/LICENSE.txt).
- Font binary: [SourceHanSansCN-VF.otf.woff2](public/fonts/source-han-sans-cn/SourceHanSansCN-VF.otf.woff2).
- Integrity and provenance: [SOURCE.json](public/fonts/source-han-sans-cn/SOURCE.json). The downloaded file's Git blob hash was checked against Adobe's repository metadata.

The official CN subset font is distributed unchanged. The website does not modify or rename its internal font data. The font is served from the same site and applies to CJK characters and punctuation through the ranges in `src/fonts.css`.

English letters and digits retain the existing system font stack. No proprietary system font binaries are included in this project. Text already embedded within uploaded artwork remains part of those original images.
